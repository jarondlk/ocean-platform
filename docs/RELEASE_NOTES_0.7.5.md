# OCEAN v0.7.5 — historical SST in normal system use

Prepared release; deployment acceptance is recorded separately.

The existing Miyagi 2020–2023 MUR dataset is promoted from the demo-only presentation to ordinary system use, following the user's explicit operational acceptance on 2026-10-08. Overview counts and coverage, Data SST, Explore, source filters and normal Chat retrieval include the immutable regional publication. Linked ANEMONE frequency analyses retain their original IDs, source bindings, result rows and separate methods/protocols, and appear as published regional analyses.

## Available evidence

- 1,455 final MUR v4.1 regional days (366/363/364/362 by year), plus the original current SST dataset. The two products render separately; their temperatures are not combined into a single series or mean.
- Six empty final-series dates: 2021-02-20, 2021-02-21, 2022-11-09, 2023-04-22, 2023-12-01 and 2023-12-02. Interim 04.1nrt remains excluded. Chart paths break at missing dates.

## Usage

Choose SST in Chat, optionally select `mur-miyagi-2020-2023` and a date range. Ordinary retrieval can cite historical coverage and daily regional temperatures. For exact fish rankings or high/low comparisons, enable ANEMONE eDNA too, select the published Miyagi analysis, workflow and comparable assay protocol. CSV exports and result citations retain exact original analysis identities.

## Interpretation notes

SST is 0.05-degree grid-point subsampling over 38–39N / 141–142E, with cosine-latitude weighting, uncertainty ≤1°C and ≥80% valid open-ocean support. Missing ice fractions retain the open-sea mask warning. This is regional foundation analysis, not hourly station or native coastal/sample-point SST.

Fish frequencies use occurrence proxies with unresolved environmental/physical identities. Read sums are sequencing signals, not fish abundance. Relative high/low bins use the available region/season study-period baseline; comparisons cannot establish weather causation. No species-resolved Japanese-sardine or comparable spatial-distribution demo is claimed. ANEMONE remains a user-selected display label, not independent reviewer or provider endorsement.
