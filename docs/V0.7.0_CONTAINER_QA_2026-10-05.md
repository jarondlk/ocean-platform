## Residual high findings: review required

Both final images contain the same eight distinct high CVEs across 44 API / 43
frontend package records.
The primary-source checks below explain the affected paths and distribution
status as of 2026-10-05. They are review leads, not a blanket non-applicability
decision. Runtime component presence, executable privileges, caller paths and
deployment restrictions must be checked against the final image before a
release disposition. A non-root process alone does not prove unreachability.

| CVE / primary source | Affected path and remaining review |
| --- | --- |
| [CVE-2025-69720](https://security-tracker.debian.org/tracker/CVE-2025-69720) | `infocmp` command processing; Debian 13 remains vulnerable with a no-DSA disposition. Verify installed CLI and any caller/input path. |
| [CVE-2026-16742](https://security-tracker.debian.org/tracker/CVE-2026-16742) | `systemd-homed` local privilege escalation; Debian 13 remains vulnerable. Library source-package matches alone do not establish daemon presence. |
| [CVE-2026-54369](https://security-tracker.debian.org/tracker/CVE-2026-54369) | Privileged pathname-based ACL calls can follow attacker-controlled symlinks; Debian 13 fix is pending. Verify privileged callers and writable inputs. |
| [CVE-2026-76642](https://security-tracker.debian.org/tracker/CVE-2026-76642) | Failed external mount helper followed by privileged post-hooks; Debian 13 remains vulnerable. Verify helper/mount paths and authorization. |
| [CVE-2026-78408](https://security-tracker.debian.org/tracker/CVE-2026-78408) | Privileged `nsenter --join-cgroup` can retain migration authority; Debian 13 remains vulnerable. Verify executable presence and privileged operator use. |
| [CVE-2026-78409](https://security-tracker.debian.org/tracker/CVE-2026-78409) | `X-mount.subdir` intermediate symlinks with authorized fstab entries; Debian 13 remains vulnerable. Verify fstab, kernel and caller conditions. |
| [CVE-2026-78410](https://security-tracker.debian.org/tracker/CVE-2026-78410) | Restricted bind mount path substitution and ownership/mode hooks; Debian 13 remains vulnerable. Verify fstab, writable ancestors and privileged mount use. |
| [CVE-2026-9538](https://security-tracker.debian.org/tracker/CVE-2026-9538) | Perl `Archive::Tar` before 3.10 accepts oversized entry headers; Debian 13 remains vulnerable. Verify module presence and untrusted archive consumers. |

Do not mix Debian unstable packages into the runtime to silence these records.
Retain complete reports, record per-image applicability or accepted residual risk,
and recheck available stable updates before the final release build. Scientific
evidence, fresh active-data/backup checks, final source/image alignment and live
candidate acceptance remain independent release gates.
