# Component prompt index

Copy **one** prompt into the Planning Hub or a fresh chat in this repository.
Planning-only is the current authorized action. The implementation and resume
prompts below are dormant instructions for a later explicit user choice.
A new chat preserves continuity through files; it does not reset account limits.

Every prompt reads the same durable plan and its exact prerequisites. Missing
prerequisites block dependent implementation, not planning. Work only on the
chosen component, save checkpoint evidence, and never automatically advance.
No handoff exists yet; create it only when implementation is selected.
