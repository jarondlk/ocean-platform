## Completed contract and consumers

The 47-case shared fixture is [schema/csv_serialization_cases.json](../../../../schema/csv_serialization_cases.json).
Apostrophe escaping applies only to original strings and string headers whose
first non-whitespace character is =,+,-,@, or whose original first character is
tab/CR/LF. Apply this protection before normal quote doubling and CSV quoting.
Numeric negatives retain their sign without apostrophe; textual negatives stay
text. Null/undefined are empty, booleans lowercase, and objects/arrays compact
Unicode JSON. The explicit whitespace set is the union of Python/ECMAScript
whitespace, including BOM and their differing control-code definitions.

`frontend/lib/csv.ts` exports the single TypeScript escapeCsvCell policy and keeps
rowsToCsv, inferColumns and safeCsvFilename behavior. Headers use a one-argument
map callback, avoiding the map index becoming the alwaysQuote flag. V1 safeCell
in exports.ts delegates with alwaysQuote=true; adminCsv imports that wrapper.
Legacy LF/minimal quoting, v1 table BOM/CRLF/always quoting and admin disclaimer/
BOM ownership stay as before. Both Next builds validate the shared source import.

`api/csv_serialization.py` centralizes csv_text, escape_csv_cell and rows_to_csv.
All three consumers—eDNA evidence, analysis CSV and administrator feedback—use
this module. Dynamic header display is escaped while rows are looked up by their
original keys. Fixed column order, CRLF/final record terminator, filenames,
provenance/operational columns, limits and X-Export-Truncated remain intact.
Administrator audit/permissions and BOM remain intact. No mutable data is rewritten.

The CSV apostrophe is an intentional presentation/display behavior; generic CSV
readers can show it literally. JSON/structured retained records keep original
values. Feedback reason arrays now display compact JSON instead of semicolon
joining, retaining every reason. Native JSON insertion/numeric-key ordering and
number/exponent spellings can differ between Python and ECMAScript outside the
explicit fixtures; C07 does not define a new canonical scientific JSON encoding.
