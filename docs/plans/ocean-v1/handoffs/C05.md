## Completed checkpoints

### Query embedding isolation (F06)

`db/embedding_identity.py` defines a frozen provider/model/dimension witness and
a list-compatible `IdentifiedEmbedding`. `db/vector_store.embed_query` captures
the actual runtime provider, selected model and returned dimension; it rejects
nonfinite/invalid vectors and returned/configured dimension disagreement.
`embed_text` retains its bare-list API for other existing consumers.

`db/vector_store.search_similar` and `retrieval/hybrid_retriever.hybrid_search`
require stored provider/model/dimension equality before vector ranking, alongside
existing active/source/scope predicates. Equal-dimensional different-model vectors
and missing identities cannot rank. Callback vectors must explicitly carry an
identity; configuration never attests an arbitrary bare list. The unified cached
query callback now supplies this witness while local NumPy use remains compatible.

Hybrid vector and text branches use independent transactions and parameter sets.
An empty compatible set, invalid callback or actual fixed-width vector SQL failure
still permits authorized FTS. Per-source diagnostics report vector status, actual
identity and scoped overfetch result count; they do not reveal global corpus counts.
Top-k defaults, fusion and result shapes remain compatible. The source-aware
wrapper deep-copies each branch diagnostic.

### Canonical metagenome mapping (F08)

Producer fields are `top_kraken_genera_json`, `top_metaeuk_genera_json` and
`top_kraken_upper_groups_json`. Producer, document builder, database sample loader,
lineage and taxa API use the same contract in `preprocessing/metagenome_contract.py`.
`adapt_legacy_metagenome_context` accepts the verified complete historical
left-Kraken `_x`/right-MetaEuk `_y` pair, or unsuffixed genus JSON with exclusive
explicit method coverage. Mixed/incomplete/ambiguous layouts and malformed or
contradictory scientific fields fail visibly. Unknown coverage is false;
nonempty string flags are rejected. Stable taxon tie ordering makes repeated
producer output deterministic. Both method labels occur exactly once in fixtures.

Generated metadata binds the canonical source-row SHA256, `metagenome-fields-v2`,
`metagenome-document-v2`, title/text content SHA256 and full generation SHA256.
The generation witness covers generated scientific/provenance fields and metadata;
mutable active/embedding state remains separate. IDs are
`meta_<sample_id>_v2_<generation_hash[:32]>` (at most 105 characters for allowed
64-character samples). Full generation hashes remain stored. Formatting-only JSON
changes and equivalent legacy normalization produce the same identity. Changed
unrendered source or generated evidence gets a fresh identity even if text matches.

### Rebuild and preserved history

and old metagenome-row inactivation for represented samples share the existing
advisory-locked transaction. Old IDs, text, metadata and vectors are retained.

version stripping/downgrade or changing the source family under a reserved v2 ID

The dry-run planner estimates represented-sample inactivations.
