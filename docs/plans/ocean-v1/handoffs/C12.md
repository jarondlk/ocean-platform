## Limits and recovery

Only two target methods support eligible scientific populations; four methods
remain visible in raw inventory. Alternatives never form one independent read
count. Reads are not organism abundance. Source occurrence/assay units do not
establish physical sample identity, so physical counts remain null. Frequency
requires one explicit method, protocol and taxon, and positive reads exceed zero.
Unknown/coarse dates stay visible but cannot support an exact time predicate.
Missing inputs, partial completeness and unsafe exact browser integers return
qualified unknown/unavailable results rather than invented zero or rounded counts.

Trusted current policy still supplies dataset permission and scientific eligibility;
C14 retains authenticated integration and finer access enforcement. C09 permits
one schema version per role/source, so mixed retained/unavailable classification
schemas cannot share one source registration. Rows total at most 2,000,000 and
Arrow decoded buffers at most 512 MiB per snapshot; this is not a production memory
or throughput certification. No live fallback or retrieval readiness requirement exists.

Actual source mapping/copying/acquisition, classification/review changes, physical
identity inference, scientific regeneration/approval, publication, service/UI
integration and cloud deployment remain outside local C12 acceptance. Rollback
disables additive C12 exposure/registrations while retaining frozen bytes,
classification lineage, provenance, receipts and current access policy.
