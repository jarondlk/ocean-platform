## Runtime and boundaries

Node 22.14.0, npm 10.9.2. From frontend-v1:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm run typecheck
npm test
npm run build
npm run preview
```

Preview: http://127.0.0.1:3100, loopback only. The static server reads out/; rebuild
and reload after changes. Ctrl-C stops it. Current agent-started preview session
48354 remains running for review. `npm run dev` is the alternative with hot reload;
stop the static server first. Initial dependency install used the local npm cache.
No credentials/environment file/backend are required.

Dedicated /about, /feedback and /admin routes support direct navigation/reload.
Research/catalogue/tools use query navigation and browser history. Synthetic
investigations/feedback/preferences use ocean-p00-synthetic-v1; admin uses
versioned ocean-p00-admin-v1. Corrupt storage falls back safely, storage failures
are visible, and Reset sample data clears both stores. First-iteration drafts
migrate without loss. Role restrictions are UI simulations, not security proof.

Legacy frontend/backend and cloud/runtime configuration are unchanged. No real
authentication, provider call, Python execution, scientific data transfer or deployment.
