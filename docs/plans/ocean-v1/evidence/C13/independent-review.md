# C13 implementation and independent review

Date: 2026-10-16 JST. Scope: local software and explicit synthetic frozen inputs.

Three delegated slices audited prerequisites, implemented frozen contracts and
reviewed the scientific adapter independently. The primary agent applied their
findings and verified the final source. The delegates reached account limits
during final review; their completed tests and reported findings were preserved.
This report does not claim independent scientific approval or real-data acceptance.

## Findings and resolutions

- **Mutable discovery:** existing publication/options/registry helpers discover
  configuration, pointers or databases. C13 instead consumes a verified C09 index,
  full retained table bytes and exact child snapshot bindings. Bounded answer
  packets and option lists never establish catalogue completeness.
- **Frozen C02 eligibility:** a backward-compatible explicit tombstone parameter
  avoids live invalidation-file reads for C13, while existing consumers keep their
  configured behavior. Output/input/method/generation/review checks remain shared.
  Legacy and invalidated outputs cannot regain eligibility through copying.
- **Source decoder budgets:** the C10 footer schema version was corrected, and
  combined index/source row and decoded-byte bounds are checked before scientific
  callbacks. Actual decoded sizes are checked after source decoding. No process
  resident-memory guarantee is claimed.
- **Mixed source snapshots:** shared C10 CTD/metagenome child snapshots are loaded
  once and their hierarchies are built with the correct family scope. The index's
  CTD storage carrier never grants CTD scientific membership or a dataset count.
- **Canonical collisions:** complete source artifact/dataset and parsed hierarchy
  IDs, including collections, products and generated directories, are reserved
  before source/scientific visibility can hide an invalid conflict.
- **Current policies:** raw source policies receive dataset metadata; scientific
  policies receive detached analysis/workflow/definition/relationship models.
  Every decision requires literal True; all required inputs must remain allowed.
- **Table paging:** the final-page preview flag now follows the existing C08
  full-population receipt rule. All 1,205 retained published rows remain reachable;
  exact totals/content hashes do not depend on the preview size or offset.
- **Cross-root membership:** 1,205 actual sealed source datasets are counted over
  complete descendants, deduplicating canonical IDs across scientific links.
- **Discoverable actions:** copied native actions are replaced with C13-routable
  actions on index envelopes. Inspection preserves native operation IDs/versions.
  Unsupported source quality operations return qualified unknown availability.
- **Private metadata:** receipts contain only the index object, selected result
  table and actual permitted child dependencies. Denied table IDs/hashes and
  denied workflow analysis links are not exposed through other operations.
- **C01 compatibility:** fixed published scope cannot be narrowed to inherit a
  finding. Registered publication workflows require their actual scientific
  source families, protocol and exact existing C01 field-level receipt.
- **Relationship authority:** applied physical registries verify full review and
  application chains plus source hashes, active occurrences/representative assay
  and reviewed areas. Reviewed matching, environmental proximity and unresolved
  associations remain separate; none grants comparison or experiment authority.
- **Approval claims:** current operational-publication records strictly retain
  false independent approval/endorsement flags. Published lifecycle never creates
  scientific approval; private/unpublished experiments stay outside global Analyses.
