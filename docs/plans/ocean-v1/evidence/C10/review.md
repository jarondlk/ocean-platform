# C10 source review and independent reference acceptance

Review: root source audit and independent expected-value tests; no separate agent
review is claimed. Implementation remains local/synthetic until final verification.

The reference tests calculate cast/depth membership and temperature aggregates
from explicit range/formula expectations, and test beyond-ranked normalized taxa
with known per-method constants. Every depth identity across more than 500 rows
is independently enumerated. Old snapshots and imported copies run through the
actual C09 store and C10 adapter; receipts bind the bytes subsequently verified.

Reviewed source ownership, exact metadata/object membership, Parquet primitive
schemas, row identities/foreign keys, full normalized cell grids, method coverage,
unknown units/denominators, precision and request/access boundaries. All operations
apply eligibility/scope before pagination and do not invoke ranking/models.

Resolved during review: frozen export registrations now require an explicit exact
source generation rather than relabelling old bytes under a fresh head. Scoped
capture and enabled-but-absent source flags cannot become complete inventories.
Plain Parquet encodings are enforced before decoding to avoid unbounded repeated
string expansion. Missing roles require explicit unavailable descriptors. Signed
source depths and per-record mixed precision are retained without invented rules.

No authenticated role/session or row-level access service, actual copied-data
parity, production-throughput/RAM bound, real publication or deployment is claimed.
Trusted current callbacks cover complete source datasets. These limitations and
future service responsibilities are recorded in C10_ADAPTER_CONTRACT.md.
