## Legacy history (read only when tracing a past decision)

- `RELEASE_NOTES_*`, `RELEASE_*_OPERATIONS`, `RELEASE_*_PLAN`, `RELEASE_*_IMPLEMENTATION`
  and `V0.*` QA files: one set per legacy release.
- `ANEMONE_*`: eDNA integration plans, pilots and QA (Sept–Oct 2026).
- `HISTORICAL_SST_*`, `OVERVIEW_*`, `MIYAGI_PROVISIONAL_DEMO_*`: SST work for
  the October demonstrations.
- `CONFERENCE_*`, `AUTO_CHAT_SETTINGS_*`, `ISSUE_59_*`, `CHAT_QA_*`: dated
  feature and incident records.
- `screenshots/`: legacy UI screenshots used by the root README.

The October repository audits and model benchmark (`REPOSITORY_AUDIT_*`,
`LLM_MODEL_BENCHMARK_*`, `audits/`, `benchmarks/`) exist only as local,
uncommitted copies on the operator's Mac. They are pinned by the C26
acceptance receipt and must not be edited.
